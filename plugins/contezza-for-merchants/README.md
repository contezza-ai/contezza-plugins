# contezza-for-merchants

**Contezza AI for Merchants** — trusted merchant knowledge for AI agents, in
Claude Code and Cowork: author Verified
Answers feeds (`verified-feed-authoring`), wire them under Anthropic's
commerce-agents blueprint (`adapter-quickstart`), lint feeds with `/feed-lint`, and query Contezza's
verified layer over MCP (`mcp.contezza.ai/ecommerce/mcp`, read-only, no auth);
a `setup` skill verifies the connection.

Part of the [contezza-plugins](https://github.com/contezza-ai/contezza-plugins)
marketplace · [contezza.ai](https://contezza.ai) · Apache-2.0
